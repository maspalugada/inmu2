# live-app

**live-app** is a powerful yet user-friendly live video production and streaming application for Windows.

This repository contains the source code and project files for the application.

## Directory Structure

- **/src**: Contains the source code for the application.
  - **/LiveApp.Core.Cpp**: The C++ backend responsible for video/audio processing via GStreamer.
  - **/LiveApp.UI.CSharp**: The C# WPF frontend for the user interface.
- **/docs**: Contains project documentation, including the project overview, feature list, and design documents.
- **/scripts**: Build scripts, dependency installation scripts, etc.
- **/assets**: Icons, images, and other assets used in the application.

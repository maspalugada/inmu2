# live-app User Guide

This guide will help you get started with live-app.

## System Requirements

*   Windows 10 or later
*   .NET 6.0 Runtime
*   GStreamer 1.0 (MSVC 64-bit)

## Installation

1.  Download the latest installer from the [releases page](https://github.com/your-username/live-app/releases).
2.  Run the installer and follow the on-screen instructions.

## Getting Started

1.  Launch live-app from the Start Menu or the desktop shortcut.
2.  The main window is divided into several sections:
    *   **Preview:** This is where you can prepare your scenes before they go live.
    *   **Program:** This is what your audience sees.
    *   **Scenes:** A list of your scenes.
    *   **Sources:** A list of the sources in the selected scene.
    *   **Audio Mixer:** Controls for the audio of each source.

## Basic Features

### Scenes and Sources

*   **Scenes:** A scene is a collection of sources that are arranged in a specific way. You can create multiple scenes and switch between them during your broadcast.
*   **Sources:** A source is a video or audio input. live-app supports the following sources:
    *   Webcams
    *   Screen capture
    *   Video files

### Preview and Program

*   The **Preview** window is where you can edit your scenes before they go live. You can add, remove, and reposition sources in the Preview window.
*   The **Program** window shows what your audience is currently seeing.

### Transitions

*   To transition a scene from the Preview window to the Program window, click the **Transition** button.

### Audio Mixing

*   The **Audio Mixer** allows you to control the audio of each source. You can adjust the volume and mute the audio of each source individually.
